JavaScript 常用字符串方法完全解析

前提认知:字符串是不可变的 —— 所有字符串方法都不会修改原字符串,而是返回新的字符串或数组;下标赋值 str[0] = 'x' 无效(严格模式报错).

一、常用字符串方法总览(按用途分类)

用途分类 方法 返回值 是否修改原字符串 核心作用
长度 / 取字符 length(属性) 数字 否 字符个数(UTF-16 码元数)
at / charAt / charCodeAt 字符 / 编码数字 否 按下标取字符或字符编码
查找 indexOf / lastIndexOf 下标 / -1 否 子串首次 / 最后出现的位置
includes 布尔值 否 是否包含子串(推荐)
startsWith / endsWith 布尔值 否 是否以某串开头 / 结尾
截取 slice 新字符串 否 截取,支持负数索引(推荐)
substring 新字符串 否 截取,自动交换参数,不支持负数
substr(已废弃) 新字符串 否 截取,第二个参数是长度
格式化 trim / trimStart / trimEnd 新字符串 否 去除首尾 / 开头 / 结尾空格
padStart / padEnd 新字符串 否 补位到指定长度
repeat 新字符串 否 重复指定次数
toUpperCase / toLowerCase 新字符串 否 转大写 / 小写
替换 replace / replaceAll 新字符串 否 替换首个 / 全部匹配项
分割 / 转换 split 数组 否 字符串 → 数组(与 join 互逆)
正则相关 match / matchAll / search 数组 / 迭代器 / 下标 否 正则匹配、提取、定位
比较 / 其他 localeCompare 负数 / 0 / 正数 否 本地化比较(配合 sort 排序)

二、长度与取字符(length / at / charAt / charCodeAt)

const str = 'hello world';

console.log(str.length);        // 11
console.log(str[0]);            // 'h'(只读,不能赋值)
console.log(str.at(-1));        // 'd'(at 支持负数,推荐)
console.log(str.charAt(0));     // 'h'(越界返回 '')
console.log(str.charCodeAt(0)); // 104(UTF-16 编码)
console.log(String.fromCharCode(72, 105)); // 'Hi'(编码 → 字符)

// emoji 等特殊字符占 2 个码元,要用码点或展开运算符处理
const emoji = '😀';
console.log(emoji.length);        // 2
console.log([...emoji].length);   // 1(按真正的字符算)
细节:str.at(-1) 等价于 str[str.length - 1],但写法更简洁; charAt 越界返回空串,而 [ ] 越界返回 undefined.

三、查找与判断(indexOf / lastIndexOf / includes / startsWith / endsWith)

1. indexOf / lastIndexOf:返回下标,找不到返回 -1

const str = 'hello world';

console.log(str.indexOf('world'));    // 6(首次出现)
console.log(str.indexOf('o', 5));     // 7(从下标 5 开始找)
console.log(str.lastIndexOf('o'));    // 7(最后一次出现)
console.log(str.indexOf('abc'));      // -1(不存在)

2. includes / startsWith / endsWith:返回布尔值(推荐用于判断)

console.log(str.includes('llo'));       // true
console.log(str.includes('llo', 5));    // false(从下标 5 开始找)
console.log(str.startsWith('hello'));   // true
console.log(str.endsWith('world'));     // true
console.log(str.endsWith('hello', 5));  // true(只判断前 5 位)
细节:只判断「有没有」时优先用 includes,不要写成 indexOf(x) !== -1;indexOf 只支持字符串,正则匹配要用 search.

四、截取三兄弟对比(slice / substring / substr)

方法 参数含义 负数值 start > end 时 状态
slice(start, end) 起始下标, 结束下标(不含) 支持,从末尾倒数 返回空串 推荐使用
substring(start, end) 起始下标, 结束下标(不含) 不支持,按 0 处理 自动交换两个参数 可用
substr(start, length) 起始下标, 截取长度 start 支持负数 无此概念 已废弃,不要用 
const str = 'hello world';

// slice:推荐,支持负数
console.log(str.slice(0, 5));    // 'hello'
console.log(str.slice(6));       // 'world'(省略 end 表示到末尾)
console.log(str.slice(-5));      // 'world'(从末尾倒数 5 个)
console.log(str.slice(0, -6));   // 'hello'
console.log(str.slice(6, 2));    // ''(start > end 返回空串)

// substring:不支持负数,会自动交换参数(容易踩坑)
console.log(str.substring(0, 5)); // 'hello'
console.log(str.substring(5, 0)); // 'hello'(自动交换)
console.log(str.substring(-3));   // 'hello world'(负数当成 0)

// substr:第二个参数是长度(已废弃)
console.log(str.substr(6, 3));    // 'wor'
坑点:substring 会把负数当 0 处理,又会在 start > end 时自动交换参数, 结果往往和直觉相反 —— 新代码统一用 slice 即可.

五、修改与格式化(trim / pad / repeat / replace / 大小写)

1. 大小写与去空格

console.log('aBc'.toUpperCase());   // 'ABC'
console.log('aBc'.toLowerCase());   // 'abc'
console.log('  hi  '.trim());       // 'hi'
console.log('  hi  '.trimStart());  // 'hi  '
console.log('  hi  '.trimEnd());    // '  hi'

2. 补位与重复:padStart / padEnd / repeat

console.log('5'.padStart(3, '0'));   // '005'(常用于时间、编号格式化)
console.log('5'.padEnd(3, '-'));     // '5--'
console.log('中文'.padEnd(4, '*'));  // '中文**'
console.log('ab'.repeat(3));         // 'ababab'

3. 替换:replace / replaceAll

const str = 'hello world';

console.log(str.replace('world', 'js'));   // 'hello js'(只替换第一个)
console.log('a-b-c'.replace('-', '+'));    // 'a+b-c'
console.log('a-b-c'.replaceAll('-', '+')); // 'a+b+c'(ES2021,全部替换)
console.log(str.replace(/l/g, '*'));       // 'he**o wor*d'(正则 + g 也能全替换)
细节:padStart 的第一个参数是「总长度」,不足才补; 补位字符默认是空格.时间格式化常写成 String(h).padStart(2, '0').

六、分割与转换(split / Array.from / 展开运算符)

const str = 'hello world';

console.log(str.split(' '));      // ['hello', 'world']
console.log(str.split(''));       // 按单个字符拆开
console.log([...str]);            // 同上,但能正确处理 emoji
console.log('a,b,c'.split(',', 2)); // ['a', 'b'](第二个参数限制数组长度)
console.log(['hello', 'world'].join('-')); // 'hello-world'(与 split 互逆)
console.log(Array.from('abc'));   // ['a', 'b', 'c']
细节:split('') 会按「码元」拆分,emoji 会被拆成两半出错; 要按真正的字符拆分请用 [...str] 或 Array.from(str).

七、正则相关(match / matchAll / search)

const str = 'a1b22c333';

console.log(str.search(/wor/));            // 返回下标(支持正则的 indexOf)
console.log(str.match(/\d+/));             // 第一个匹配:'1'
console.log(str.match(/\d+/g));            // 全部匹配:['1', '22', '333']
console.log([...str.matchAll(/\d+/g)]);    // matchAll 返回「迭代器」,要展开
console.log(str.matchAll(/\d+/g).next().value[0]); // '1'
细节:matchAll 必须带 g 标志,且返回的是迭代器, 一般要 [...str.matchAll(/x/g)] 或配合 for...of 使用.

八、其他实用方法(localeCompare / String.raw / toFixed)

// 1. localeCompare:本地化比较,返回负数/0/正数,排序时用
console.log('a'.localeCompare('b'));  // -1(a 排在 b 前)
const arr = ['b', 'a', 'c'];
console.log(arr.sort((x, y) => x.localeCompare(y))); // ['a', 'b', 'c']

// 2. String.raw:原样输出,不处理转义字符
console.log(String.raw`C:\new\test`); // C:\new\test

// 3. 数字 → 字符串
const num = 123.456;
console.log(num.toFixed(2));   // '123.46'(保留 2 位小数)
console.log(num.toString());   // '123.456'
console.log(String(num));      // '123.456'

九、实战综合案例

// 1. 手机号脱敏:13812345678 → 138****5678
const phone = '13812345678';
const hidePhone = phone.slice(0, 3) + '****' + phone.slice(-4);

// 2. 判断回文:去空格、统一小写后,正着读和倒着读相同
function isPalindrome(text) {
    const clean = text.replace(/\s/g, '').toLowerCase();
    return clean === [...clean].reverse().join('');
}

// 3. 统计每个字符出现的次数
const count = {};
for (const ch of 'hello') {
    count[ch] = (count[ch] || 0) + 1;
}

// 4. 首字母大写(单词)
function capitalize(text) {
    return text.charAt(0).toUpperCase() + text.slice(1).toLowerCase();
}

// 5. 解析 URL 查询串为对象(简单版)
function parseQuery(url) {
    const query = url.split('?')[1];
    if (!query) return {};
    return Object.fromEntries(query.split('&').map(item => item.split('=')));
}

十、字符串方法使用原则

  • ✅ 记住字符串不可变:所有方法返回新值,想生效必须接收返回值;
  • ✅ 截取统一用 slice,支持负数、行为可预期,避开 substring/substr 的坑;
  • ✅ 判断包含用 includes,别写 indexOf(x) !== -1;
  • ✅ 字符串 ↔ 数组靠 split / join,要按字符拆时用 [...str] 处理 emoji;
  • ✅ 补位格式化用 padStart,例如时间、编号补 0;
  • ✅ 批量替换新环境用 replaceAll,老环境用 replace(/x/g, '');
  • ❌ 不要用 substr,已废弃,新代码改用 slice(注意第二个参数含义不同).
