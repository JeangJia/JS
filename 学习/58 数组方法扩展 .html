JavaScript 常用数组方法完全解析

二、基础遍历/转换方法(forEach/map/join)

三、筛选/查找方法(filter/find/findIndex/indexOf/includes)

1. filter:筛选符合条件的元素,返回新数组

const arr = [1,2,3,4,5,6];
// 筛选偶数
const evenArr = arr.filter(item => item % 2 === 0); 
console.log(evenArr); // [2,4,6]

2. find:查找第一个符合条件的元素,无则返回undefined

const users = [{id:1,name:'张三'},{id:2,name:'李四'}];
// 查找id=2的用户
const user = users.find(item => item.id === 2); 
console.log(user); // {id:2,name:'李四'}

3. findIndex:查找第一个符合条件的元素索引,无则返回-1

const arr = [10,20,30];
const index = arr.findIndex(item => item === 20); 
console.log(index); // 1

4. indexOf/lastIndexOf:查找元素索引(值匹配)

const arr = [1,2,3,2,1];
console.log(arr.indexOf(2)); // 1(首次出现位置)
console.log(arr.lastIndexOf(2)); // 3(最后出现位置)

5. includes:判断数组是否包含指定元素,返回布尔值

const arr = [1,2,3];
console.log(arr.includes(2)); // true
console.log(arr.includes(4)); // false
细节:find/findIndex 支持「条件匹配」(函数),indexOf/includes 仅支持「值匹配」;includes 可判断 NaN(indexOf 不行).

四、判断验证方法(every/some)

1. every:所有元素满足条件返回true,否则false(全满足)

const arr = [2,4,6,8];
// 是否全为偶数
const isAllEven = arr.every(item => item % 2 === 0); 
console.log(isAllEven); // true

2. some:至少一个元素满足条件返回true,否则false(有满足)

const arr = [1,3,5,6];
// 是否有偶数
const hasEven = arr.some(item => item % 2 === 0); 
console.log(hasEven); // true
细节:every/some 都是「短路操作」_ every 遇到第一个不满足的元素立即返回;some 遇到第一个满足的元素立即返回.

五、修改原数组的方法(push/pop/unshift/shift/splice/sort/reverse)

1. 尾部操作:push(增)/ pop(删)

const arr = [1,2,3];
arr.push(4); // 尾部加元素,返回新长度 4 → arr: [1,2,3,4]
arr.pop(); // 尾部删元素,返回删除的 4 → arr: [1,2,3]

2. 头部操作:unshift(增)/ shift(删)

const arr = [1,2,3];
arr.unshift(0); // 头部加元素,返回新长度 4 → arr: [0,1,2,3]
arr.shift(); // 头部删元素,返回删除的 0 → arr: [1,2,3]

3. 任意位置:splice(增/删/改)

const arr = [1,2,3,4,5];
// splice(起始索引, 删除数量, 新增元素1, 新增元素2...)
arr.splice(2, 1); // 删除索引2的元素 → arr: [1,2,4,5]
arr.splice(2, 0, 3); // 索引2处新增元素3 → arr: [1,2,3,4,5]
arr.splice(2, 1, 9); // 替换索引2的元素 → arr: [1,2,9,4,5]

4. 排序/反转:sort/reverse

const arr = [3,1,2];
arr.sort(); // 默认按字符串排序 → [1,2,3]
arr.sort((a,b) => a - b); // 数字升序排序
arr.sort((a,b) => b - a); // 数字降序排序
arr.reverse(); // 反转数组 → [3,2,1]
注意:sort 默认是「字符串排序」,数字排序必须传比较函数;以上方法都会直接修改原数组!

六、不修改原数组的拼接/截取(concat/slice)

1. concat:拼接多个数组/值,返回新数组

const arr1 = [1,2];
const arr2 = [3,4];
const newArr = arr1.concat(arr2, 5); // 拼接arr1+arr2+5 → [1,2,3,4,5]

2. slice:截取数组部分元素,返回新数组

const arr = [1,2,3,4,5];
// slice(起始索引, 结束索引):包含起始,不包含结束
const part1 = arr.slice(1, 3); // [2,3]
const part2 = arr.slice(2); // 从索引2到末尾 → [3,4,5]
const part3 = arr.slice(-2); // 最后2个元素 → [4,5]
细节:slice 不修改原数组;结束索引省略则截取到末尾;负数索引表示从尾部倒数.

七、聚合计算方法(reduce/reduceRight)

1. reduce:从左到右遍历,聚合为单个值(万能方法)

const arr = [1,2,3,4];
// 语法:reduce((累计值, 当前值, 索引, 原数组) => {}, 初始值)

// 求和(带初始值)
const sum = arr.reduce((total, item) => total + item, 0); // 10

// 求最大值
const max = arr.reduce((prev, item) => prev > item ? prev : item, arr[0]); // 4

// 数组转对象
const users = [{id:1,name:'张三'},{id:2,name:'李四'}];
const userObj = users.reduce((obj, item) => {
    obj[item.id] = item.name;
    return obj;
}, {}); // {1:'张三', 2:'李四'}

2. reduceRight:从右到左遍历(用法同reduce)

const arr = [1,2,3];
const str = arr.reduceRight((total, item) => total + item, ''); // "321"
细节:初始值可选,但建议必传(无初始值时,累计值初始为第一个元素,遍历从第二个开始).

八、实战综合案例

// 需求:处理用户数据
const users = [
    { id: 1, name: '张三', age: 18, score: 85, status: true },
    { id: 2, name: '李四', age: 20, score: 92, status: true },
    { id: 3, name: '王五', age: 19, score: 78, status: false },
    { id: 4, name: '赵六', age: 21, score: 95, status: true }
];

// 1. 筛选状态为true且分数≥80的用户
const validUsers = users.filter(u => u.status && u.score >= 80);

// 2. 提取这些用户的姓名和分数,生成新数组
const userInfo = validUsers.map(u => ({ name: u.name, score: u.score }));

// 3. 计算这些用户的平均分
const avgScore = userInfo.reduce((total, u) => total + u.score, 0) / userInfo.length;

// 4. 判断是否有用户分数≥90
const hasHighScore = userInfo.some(u => u.score >= 90);

console.log(validUsers, userInfo, avgScore, hasHighScore);

九、数组方法使用原则

  • ✅ 优先使用不修改原数组的方法(map/filter/slice/concat),避免副作用;
  • ✅ 遍历执行操作用forEach,数据转换用map,筛选用filter;
  • ✅ 查找元素优先用find(条件)/includes(值),替代indexOf;
  • ✅ 聚合计算用reduce(求和、求最大值、数组转对象等);
  • ❌ 修改原数组前先复制(如 [...arr] 或 arr.slice()),避免污染原数据;
  • ❌ sort排序数字必须传比较函数,避免字符串排序陷阱.
