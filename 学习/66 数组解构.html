JavaScript 数组解构(Array Destructuring)

一、数组解构的核心概念

数组解构是 ES6 新增的语法糖,用于将数组的元素批量赋值给变量,本质是「模式匹配」_ 按照数组的结构,将对应位置的元素赋值给对应位置的变量,简化数组元素的提取操作.

// 基础语法
let 数组 = [值1, 值2, 值3];
let [变量1, 变量2, 变量3] = 数组; // 按位置匹配赋值

二、数组解构的核心用法(含细节)

1. 基础解构:按位置匹配赋值

最核心的用法,变量的顺序对应数组元素的顺序,数量可不一致.

// 完整匹配
let arr = [1, 2, 3];
let [a, b, c] = arr; // a=1, b=2, c=3

// 变量数 < 数组元素数:只取前N个
let [d, e] = arr; // d=1, e=2

// 变量数 > 数组元素数:多余变量赋值为 undefined
let [f, g, h, i] = arr; // f=1, g=2, h=3, i=undefined

2. 忽略指定元素

用「空逗号」跳过不需要的元素,逗号数量对应跳过的位置.

let arr = [1, 2, 3];
let [d, , e] = arr; // 跳过第二个元素,d=1, e=3
let [, , k] = arr;  // 跳过前两个元素,k=3
细节:空逗号的位置必须和跳过的元素位置严格对应,不能多/少逗号.

3. 设置默认值

当数组对应位置的元素为 undefined(或无该元素)时,使用默认值.

// 场景1:数组元素存在,优先使用数组值
let arr = [1, 2, 3];
let [f = 4, g = 5, h = 6] = arr; // f=1, g=2, h=3

// 场景2:数组元素为 undefined,使用默认值
let arr2 = [1, undefined, 3];
let [m = 10, n = 20, p = 30] = arr2; // m=1, n=20, p=3

// 场景3:数组长度不足,多余变量用默认值
let [q = 5, r = 6, s = 7, t = 8] = arr; // q=1, r=2, s=3, t=8
细节:只有元素为 undefined 时才会触发默认值,null/0/'' 等「假值」不会触发.
示例:let [x = 10] = [null]; → x = null(而非 10).

4. 剩余参数(...)解构剩余元素

用 ...变量名 接收数组剩余的所有元素,会打包为一个新数组.

let arr = [1, 2, 3, 4, 5];
let [i, ...j] = arr; // i=1, j=[2,3,4,5]

// 跳过元素后接收剩余
let [, k, ...l] = arr; // k=2, l=[3,4,5]

// 剩余参数必须是最后一个变量(否则报错)
let [...m, n] = arr; // SyntaxError: Rest element must be last element
注意:剩余参数 ... 只能放在解构模式的最后一位,否则会报语法错误.

5. 解构交换变量

无需临时变量,直接交换两个/多个变量的值,是数组解构的经典实用场景.

let x = 10;
let y = 20;
[x, y] = [y, x]; // x=20, y=10

// 扩展:交换多个变量
let a = 1, b = 2, c = 3;
[a, b, c] = [c, a, b]; // a=3, b=1, c=2
关键细节:交换语句前必须加 ; 分号!
原因:JavaScript 会将 [x, y] 解析为数组字面量,若前面无分号,可能和前一行代码拼接导致语法错误(如 let y = 20 [x, y] = [y, x]).

6. 解构嵌套数组

数组嵌套时,解构模式需和数组结构一致(多层 [] 匹配多层数组).

let arr = [1, [2, 3], 4];
// 匹配嵌套结构:第一层取1,第二层取2、3,第一层取4
let [a, [b, c], d] = arr; // a=1, b=2, c=3, d=4

// 忽略嵌套中的元素
let [e, [, f], g] = arr; // e=1, f=3, g=4

7. 解构类数组对象

只要对象有 length 属性且可索引(如 arguments、NodeList),就能用数组解构.

// 解构 arguments(函数参数类数组)
function test() {
    let [a, b] = arguments;
    return [a, b];
}
test(10, 20); // [10, 20]

// 解构 NodeList(DOM 集合)
// let [li1, li2] = document.querySelectorAll('li');

三、数组解构的常见坑与注意事项

  • 解构未声明的变量时,需加括号:
    错误:let arr = [1,2]; {x, y} = arr;(语法错误)
    正确:let arr = [1,2]; ({x, y} = arr);(加括号)
  • 解构 null/undefined 会报错:
    let [a] = null; / let [b] = undefined; → TypeError(无法解构 null/undefined)
  • 解构非可迭代对象会报错:
    let [a] = 123; / let [b] = {} → TypeError(数字/普通对象不可迭代)
  • 剩余参数不能单独使用:
    let [...a] = [1,2,3];(合法),let [...](非法)

四、数组解构的实用场景

1. 函数返回多个值

function getUserInfo() {
    return ['张三', 20, '男'];
}
let [name, age, gender] = getUserInfo(); // 一次性接收多个返回值

2. 提取数组中的特定元素

let data = ['2025-11-27', '订单1', 100, '已完成'];
let [date, , amount, status] = data; // 只提取日期、金额、状态

3. 解构赋值结合函数参数

// 直接解构函数参数(适合接收数组参数的场景)
function sum([a, b]) {
    return a + b;
}
sum([10, 20]); // 30

// 结合默认值
function print([x = 0, y = 0]) {
    console.log(x, y);
}
print([]); // 0 0

五、总结

数组解构的核心是「按位置匹配赋值」,核心价值:

  • 简化数组元素提取,替代传统的 arr[0]/arr[1] 写法;
  • 支持默认值、剩余参数、嵌套解构,适配复杂数组结构;
  • 经典场景:变量交换、函数多返回值接收、类数组解析;
  • 注意避开「解构 null/undefined」「剩余参数位置错误」等坑.
