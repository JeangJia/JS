JavaScript 闭包完全解析

一、闭包的基本概念

闭包(Closure)是指有权访问另一个函数作用域中变量的函数,简单来说:

  • 一个函数内部定义了另一个函数
  • 内部函数引用了外部函数的变量/参数
  • 外部函数执行后,内部函数被导出到外部(返回、赋值给全局变量等)
  • 外部函数的作用域不会被销毁,因为内部函数仍在引用

核心本质

闭包的本质是函数作用域链的特殊表现形式,当内部函数保存了对外部函数作用域的引用时,就形成了闭包.

最基础的闭包案例

// 外部函数
function outer() {
    // 外部函数的变量
    let message = "Hello Closure";
    
    // 内部函数(闭包)
    function inner() {
        // 访问外部函数的变量
        console.log(message);
    }
    
    // 返回内部函数,导出到外部
    return inner;
}

// 执行外部函数,得到内部函数
const closureFunc = outer();
// 执行内部函数,仍能访问外部函数的变量
closureFunc(); // 输出: Hello Closure

二、闭包的核心特性与使用场景

1. 私有化变量(模块化)

利用闭包可以创建私有变量,避免全局污染,实现模块化.

// 计数器模块(私有变量)
function createCounter() {
    // 私有变量,外部无法直接访问
    let count = 0;
    
    return {
        increment: function() {
            count++;
            return count;
        },
        decrement: function() {
            count--;
            return count;
        },
        getCount: function() {
            return count;
        }
    };
}

// 创建计数器实例
const counter1 = createCounter();
const counter2 = createCounter();

console.log(counter1.increment()); // 1
console.log(counter1.increment()); // 2
console.log(counter2.increment()); // 1(互不干扰)
console.log(counter1.getCount());  // 2
console.log(counter1.count);       // undefined(无法直接访问私有变量)

2. 保存函数执行上下文

闭包可以保存每次执行的上下文,解决循环中变量共享的问题.

// 反例:循环中直接赋值(无闭包,所有点击事件共享同一个i)
function badLoopExample() {
    const buttons = document.querySelectorAll('.bad-btn');
    for (var i = 0; i < buttons.length; i++) {
        buttons[i].onclick = function() {
            alert(`你点击了按钮 ${i}`); // 无论点哪个,都显示 3
        };
    }
}





// 正例:使用闭包保存每次的i值
function goodLoopExample() {
    const buttons = document.querySelectorAll('.good-btn');
    for (var i = 0; i < buttons.length; i++) {
        // 立即执行函数创建闭包
        (function(index) {
            buttons[index].onclick = function() {
                alert(`你点击了按钮 ${index}`); // 正确显示对应索引
            };
        })(i);
    }
}


3. 函数柯里化(参数复用)

闭包可以实现柯里化,将多参数函数转化为单参数函数的链式调用.

// 柯里化案例:计算商品总价(单价 * 数量)
function calculatePrice(price) {
    // 保存单价
    return function(quantity) {
        // 复用单价,计算总价
        return price * quantity;
    };
}

// 创建单价为100的商品计算函数
const price100 = calculatePrice(100);
console.log(price100(5));  // 500(100*5)
console.log(price100(10)); // 1000(100*10)

// 创建单价为200的商品计算函数
const price200 = calculatePrice(200);
console.log(price200(3));  // 600(200*3)

三、闭包的注意事项与常见坑

⚠️ 内存泄漏风险

闭包会保留对外部函数作用域的引用,导致外部函数的变量无法被垃圾回收(GC),如果大量使用闭包且未及时释放,会造成内存泄漏.

1. 内存泄漏案例与解决

// 危险案例:闭包引用DOM元素,导致DOM无法被回收
function attachEvent() {
    const element = document.getElementById('myElement');
    element.onclick = function() {
        // 闭包引用了element,形成循环引用
        console.log(element.id);
    };
}

// 解决方法:解除引用
function safeAttachEvent() {
    const element = document.getElementById('myElement');
    const id = element.id; // 只保存需要的属性
    element.onclick = function() {
        console.log(id);
    };
    element = null; // 解除对DOM的引用
}
⚠️ 闭包中的this指向问题

闭包内部的this默认指向window(非严格模式),而非外部函数的this,需要特别注意.

2. this指向问题案例

const obj = {
    name: "测试对象",
    outer: function() {
        console.log('外部函数this:', this.name); // 测试对象
        
        // 闭包函数
        return function() {
            console.log('闭包函数this:', this.name); // undefined(this指向window)
        };
    }
};

const innerFunc = obj.outer();
innerFunc();

// 解决方法:保存外部this
const obj2 = {
    name: "测试对象2",
    outer: function() {
        const self = this; // 保存外部this
        return function() {
            console.log('修复后this:', self.name); // 测试对象2
        };
    }
};
💡 注意:

ES6箭头函数没有自己的this,会继承外部作用域的this,可简化this指向问题:

const obj3 = {
    name: "测试对象3",
    outer: function() {
        return () => {
            console.log('箭头函数this:', this.name); // 测试对象3
        };
    }
};

3. 闭包与变量提升/块级作用域

在ES5中,var声明的变量没有块级作用域,闭包可能会引用到最后一次赋值的变量:

// ES5问题案例
function createFunctions() {
    var result = [];
    for (var i = 0; i < 3; i++) {
        result[i] = function() {
            return i;
        };
    }
    return result;
}

const funcs = createFunctions();
console.log(funcs[0]()); // 3
console.log(funcs[1]()); // 3
console.log(funcs[2]()); // 3

// 解决方法1:立即执行函数
function createFunctions2() {
    var result = [];
    for (var i = 0; i < 3; i++) {
        result[i] = (function(index) {
            return function() {
                return index;
            };
        })(i);
    }
    return result;
}

// 解决方法2:ES6 let/const(块级作用域)
function createFunctions3() {
    const result = [];
    for (let i = 0; i < 3; i++) { // let有块级作用域
        result[i] = function() {
            return i;
        };
    }
    return result;
}

四、闭包的性能优化

  • 及时释放闭包引用:不再使用的闭包函数,赋值为null,让垃圾回收器回收
  • 减少闭包层级:避免多层嵌套闭包,增加作用域链查找成本
  • 复用闭包逻辑:将通用的闭包逻辑封装为工具函数,避免重复创建
  • 避免闭包引用大对象:只引用需要的属性,而非整个大对象

优化案例

// 优化前:闭包引用整个大对象
function badClosure() {
    const bigData = {
        name: "测试",
        data: new Array(10000).fill('大量数据'), // 大数组
        id: 123
    };
    return function() {
        console.log(bigData.id); // 只需要id,但引用了整个bigData
    };
}

// 优化后:只引用需要的属性
function goodClosure() {
    const bigData = {
        name: "测试",
        data: new Array(10000).fill('大量数据'),
        id: 123
    };
    const { id } = bigData; // 解构只取需要的属性
    return function() {
        console.log(id); // 仅引用id,bigData可被回收
    };
}

// 使用完及时释放
const closure = goodClosure();
closure();
closure = null; // 释放闭包引用

五、总结

  • 闭包是内部函数引用外部函数变量形成的特殊作用域链
  • 核心价值:私有化变量、保存执行上下文、参数复用
  • 注意事项:内存泄漏、this指向、作用域问题
  • 使用原则:按需使用、及时释放、避免滥用

闭包是JavaScript的核心特性之一,掌握闭包能帮助你写出更模块化、更优雅的代码,但同时也要注意其性能影响,合理使用.
